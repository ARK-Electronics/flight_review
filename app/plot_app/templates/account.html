Using the key with logloader

Pass the key as a query parameter on the upload URL (works with clients that cannot set custom headers), or send it as a header. 

{% if base_url %}{{ base_url }}{% else %}https://YOUR_HOST{% endif %}/upload?api_key=YOUR_API_KEY

Or with headers:

Authorization: Bearer YOUR_API_KEY
# or
X-API-Key: YOUR_API_KEY

Example with curl: 

curl -X POST "{% if base_url %}{{ base_url }}{% else %}https://YOUR_HOST{% endif %}/upload?api_key=YOUR_API_KEY" \
  -F "filearg=@flight.ulg" \
  -F "email=logs@arkelectron.com" \
  -F "description=logloader" \
  -F "source=QGroundControl" \
  -F "type=personal" \
  -F "redirect=false"
